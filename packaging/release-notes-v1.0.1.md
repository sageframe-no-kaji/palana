# pālana 1.0.1

- Remote panes no longer show "remote drag: between panes only" in their footer. The [known issues](https://github.com/sageframe-no-kaji/palana/blob/main/docs/known-issues/drag-freeze.md) and the README describe how remote drags work.
- The footer hints for ZFS mode and the preview pane have a left margin.
- The live shell (⌘`) now uses the SSH configuration named by `PALANA_SSH_CONFIG` when that variable is set, like every other part of pālana. The variable is for development and testing. Without it, nothing changes.
